🎫 netkeiba登録（ブックマーク）の設定

予想ページの「🎫 馬券を組む」で作った買い目を、netkeibaの買い目リストへ1タップで入れるためのブックマークです。最初に1回だけ設定します。

このブックマークは、netkeibaの購入ページ（買い目リスト）に買い目を書き込むだけです。購入はしません。購入はいつもどおり「IPAT投票へすすむ」→IPATログイン→投票内容の確認、をご自身で行います。
netkeibaが公開していない仕組みを使っているため、netkeiba側の変更で急に動かなくなることがあります。そのときは買い目を手で入力してください。

iPhone（Safari）での設定

  1. 下の「コードをコピー」を押します。
  2. このページを開いたまま、共有ボタン（□↑）→「ブックマークを追加」→ 名前を netkeiba登録 にして保存します。
  3. ブックマーク一覧（📖）→「編集」→ いま保存した「netkeiba登録」を開き、アドレス欄の中身を全部消して、コピーしたコードを貼り付けて「完了」。

iPhone（Chrome）での設定

予想ページの「netkeibaで購入へ」は、iPhoneでは最初からChromeで開くようになっています。Chromeでも同じブックマークを登録してください（Safariのブックマークとは別です）。

  1. このページをChromeで開き、下の「コードをコピー」を押します。
  2. 右下の「…」→「ブックマークに追加」。
  3. 「…」→「ブックマーク」→ 追加したブックマークを長押し →「ブックマークを編集」。名前を netkeiba登録 に、URLを全部消してコピーしたコードを貼り付けて保存します。
  4. 使うときは、netkeibaのページでアドレス欄に「netkeiba登録」と入力し、候補に出たブックマーク（☆のマーク）をタップします。

使い方

  1. 予想ページの各レースの「🎫 馬券を組む」で、券種・馬・金額を選んで「＋ 買い目に追加」。
  2. 「netkeibaで購入へ ▶」を押すと、そのレースのnetkeiba購入ページが開きます。
  3. 開いたページで、アドレス欄をタップして「netkeiba登録」と入力し、候補に出たブックマークをタップします（ブックマーク一覧から選んでも同じです）。
  4. 「○点を買い目リストに登録しました」と出たら、金額を確認して「IPAT投票へすすむ」。

同じ買い目でもう一度タップしても二重には入りません（同じ組番は金額が上書きされます）。netkeibaの買い目リストにもともと入っていた買い目は消しません。
